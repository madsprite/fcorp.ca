F Corp associate: model notice

The chat associate on this site runs the Pebble-10M language model
(https://huggingface.co/basically-ai/Pebble-10M) by basically-ai,
licensed under the Apache License, Version 2.0 (see LICENSE-Pebble-Apache-2.0.txt).

Changes made for this site:
- Weights converted from float32 safetensors to a float16 blob (pebble-10m-base-f16.bin)
  with a JSON manifest (pebble-10m-base.json). Norms, biases and other small vectors stay
  float32. The tied output head (lm_head, identical to the token embeddings) is omitted.
- Inference is a new JavaScript port (pebble.js) that runs token by token in a Web Worker,
  instead of the original PyTorch / mamba-ssm code.
- Pebble-10M is a base model, not chat-tuned. It is steered with a short role-play header and
  example support chat, processed once and snapshotted. The live chat follows it with a
  sliding window of recent turns that fits the 512-token context. Each reply is chosen from a
  few sampled candidates, ranked by the model's own confidence, with repeats discarded.
  Transfers use fixed wording.
- Replies are dictionary-guided: a token is only sampled if every word it builds is on the
  way to a word in words.txt, with simple punctuation rules. The model still ranks all tokens.

tokenizer.json is copied unchanged from the model repository.

Senior associate (optional, WebGPU only, loaded when the visitor chooses to connect it):
- Runs Qwen2.5-0.5B-Instruct (https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct, Apache License 2.0)
  in the MLC build served by https://huggingface.co/mlc-ai, through WebLLM 0.2.86
  (https://github.com/mlc-ai/web-llm, Apache License 2.0) loaded from cdn.jsdelivr.net.
  This site does not host or modify those model files; the visitor's browser fetches and caches them.
- senior.js holds the persona prompt and fixed replies: identity questions, attempts to change
  its role, replies containing figures, and out-of-character replies get set wording instead of
  model output. Replies are checked against blocked.json, a list of FNV-1a hashes of offensive
  words built from the same blocklists as words.txt, so the words themselves are not published.

words.txt is a subset of the ENABLE word list (public domain), keeping common words by
tokenizer length, with offensive terms removed at build time using the LDNOOBW list
(CC-BY-4.0, https://github.com/LDNOOBW/List-of-Dirty-Naughty-Obscene-and-Otherwise-Bad-Words),
dsojevic/profanity-list (MIT, https://github.com/dsojevic/profanity-list) and a manual list.
Those blocklists are not distributed with this site.
